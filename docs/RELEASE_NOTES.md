# FluxPlayer release notes

Current public release notes are published in English and Spanish, in that order, on GitHub.

| Version | English | Español |
|---|---|---|
| [1.4.0](https://github.com/cbatista96/FluxPlayer/releases/tag/v1.4.0) | [Release notes](releases/1.4.0/release-notes.en.md) | [Notas de la versión](releases/1.4.0/release-notes.es.md) |

For a new release, add both language files under a directory named after the version. Include highlights, added features, changes, fixes and screenshots in the matching language. Add the same version to both changelogs. The release workflow publishes both Markdown files and assembles the GitHub description in English then Spanish.
