# FluxPlayer for Windows x64

[English](#english) · [Español](#español)

**Authenticode:** Unsigned / Sin firma

## English

Install with the setup EXE or extract the entire portable ZIP and run FluxPlayer.exe. Both include .NET and LibVLC. Verify the downloaded file against SHA256SUMS.txt.

The first binary release includes Fluent Windows controls, audio and video workspaces, playlists, a local library, synchronized lyrics, an equalizer, external subtitles, bookmarks and Spanish localization. See the [changelog](https://github.com/cbatista96/FluxPlayer/blob/main/CHANGELOG.md) and [screenshots](https://github.com/cbatista96/FluxPlayer/tree/main/docs/screenshots).

## Español

Instala con el EXE o extrae el ZIP completo y abre FluxPlayer.exe. Ambos incluyen .NET y LibVLC. Comprueba el archivo descargado con SHA256SUMS.txt.

Esta primera descarga incluye espacios de música y video, listas, biblioteca local, letras sincronizadas, ecualizador, subtítulos externos, marcadores e interfaz en español. Consulta el [historial](https://github.com/cbatista96/FluxPlayer/blob/main/CHANGELOG.md) y las [capturas](https://github.com/cbatista96/FluxPlayer/tree/main/docs/screenshots).
