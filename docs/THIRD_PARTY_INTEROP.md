# Interoperability references and attribution

The Kodi request schemas in `FluxPlayer/Data/Interop/kodi-methods.json` and `kodi-types.json` derive from the functional JSON-RPC schema in the [Kodi source repository](https://github.com/xbmc/xbmc/tree/master/xbmc/interfaces/json-rpc/schema), retrieved on 2026-10-30. Human-language description/title fields were omitted; parameter/type/permission constraints remain. Kodi is provided under **GPL-2.0-or-later** according to its [license notice](https://github.com/xbmc/xbmc/blob/master/LICENSE.md). These adapted schema resources are distributed under GPL-3.0 as permitted by that later-version option; see the repository [LICENSE](../LICENSE). Copyright belongs to the Kodi project and its contributors. Kodi software itself is not bundled.

`mpd-commands.json` records protocol command names, functional signatures and independently assigned purpose/read-write metadata from the [Music Player Daemon protocol reference](https://mpd.readthedocs.io/en/stable/protocol.html), retrieved on 2026-10-30. Explanatory prose was not copied. The catalog excludes asynchronous idle, connection termination/server shutdown, authentication as a user-executable command, binary artwork/configuration commands and message subscription/transmission commands. MPD software is not bundled. MPD protocol support here is an additional music-server integration under the original broad networking/API requirements; it is not RAAT, Roon Ready, AirPlay, NAA or Sonos compatibility.

mpv command/property names and allowed values were implemented against the [official stable manual](https://mpv.io/manual/stable/), retrieved on 2026-10-30. The application launches a separately installed trusted executable only on explicit user action. No mpv binary or libmpv library is bundled. Version/renderer/driver-dependent options can fail or require restart; this is not a license, hardware or output certification.

The new offline processing definitions reference the [official FFmpeg filter documentation](https://ffmpeg.org/ffmpeg-filters.html). They contain application-authored descriptions and fixed filter graphs for distinct algorithms. No FFmpeg binary, optional Rubber Band/libbs2b component, device driver or codec license is installed by this work. The user-selected FFmpeg must supply the requested filters and encoders.

These references describe source interoperability. They do not constitute runtime acceptance of the new functionality or support guarantees for every upstream version.
