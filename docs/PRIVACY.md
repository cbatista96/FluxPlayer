# FluxPlayer privacy / Privacidad

## English

FluxPlayer processes local media on your device. It does not require a FluxPlayer account or automatically send crash reports to the project. Settings, bookmarks, playback history, library records and optional diagnostics are stored locally. The default profile uses the FluxPlayer folders under `%APPDATA%` and `%LOCALAPPDATA%`; portable and custom profiles use their selected data folder. Windows may redirect storage for packaged apps.

When you open a network stream or use a connected feature, FluxPlayer or a tool you configure communicates with the destination you choose. Examples include media servers, metadata and subtitle providers, listening services, translation providers and casting receivers. Depending on the operation, the destination can receive search terms, media identifiers, subtitle text, account credentials or playback data. Providers have their own privacy policies. Use local playback and local tools if you do not want to use those services.

Local diagnostic files can include file paths, URLs and error details. GitHub issues are public; remove personal or confidential information before posting. Uninstalling the desktop app can retain settings for reinstall. Remove the relevant profile and cache folders to delete those records; remove exported files separately if desired.

For questions about this policy, contact the [project maintainer](https://github.com/cbatista96).

## Español

FluxPlayer procesa los archivos locales en tu dispositivo. No requiere una cuenta de FluxPlayer ni envía automáticamente informes de fallos al proyecto. Los ajustes, marcadores, historial, biblioteca y diagnósticos opcionales se guardan localmente. El perfil predeterminado usa las carpetas FluxPlayer de `%APPDATA%` y `%LOCALAPPDATA%`; los perfiles portátiles y personalizados usan la ubicación elegida. Windows puede redirigir el almacenamiento de las aplicaciones empaquetadas.

Al abrir una transmisión o usar una función conectada, FluxPlayer o la herramienta que configures se comunica con el destino elegido. Entre otros, servidores multimedia, proveedores de metadatos, subtítulos y traducción, servicios de historial de escucha y dispositivos de transmisión. Según la operación, el destino puede recibir búsquedas, identificadores de medios, texto de subtítulos, credenciales o datos de reproducción. Cada proveedor aplica su propia política.

Los diagnósticos pueden incluir rutas, direcciones y detalles del error. Las incidencias de GitHub son públicas: elimina la información privada antes de adjuntar archivos. Al desinstalar se pueden conservar los ajustes. Para borrarlos, elimina el perfil y la caché correspondientes; los archivos exportados se eliminan aparte.

Para consultas sobre esta política, contacta con el [responsable del proyecto](https://github.com/cbatista96).
