# Five hundred operations and processing capabilities — individual acceptance

F0681–F1180: 100 mpv controls, 184 Kodi methods, 116 MPD commands, 25 audio algorithms and 75 video algorithms. The 100 processing algorithms pass actual export/decode fixtures, and all 100 mpv controls pass real IPC acceptance. All 300 Kodi/MPD operations pass local wire-contract fixtures, plus 200 malformed-response/invalid-input guards; they still await real backend acceptance. The full local regression passed 1,178 groups with zero failures. These are explicit subfunctions of broad original requirements, not 500 completed original requirements. Provider/version support is conditional. See [processing scope](PROCESSING_ACCEPTANCE.md) and [backend scope](LOCAL_BACKEND_ACCEPTANCE.md).
