# Thirty additional capabilities

Completed local batch: **30 of 30 capabilities**. Each entry below maps to the original user inventory and a stable public capability ID. Baseline: 107 implemented public capabilities and 400 covered original entries. This batch adds 29 public IDs and completes existing F0048. GitHub publication remains paused by the user.

## Implemented

- [x] **01. F0132** Ten-band parametric EQ with independent frequency, gain and Q, alongside the existing graphic EQ. — Original entries: R0014,R0146,R0263,R0467. Evidence: AudioEffects / Native FluxDsp / AudioEffectsWindow. Captured PCM verifies a +6 dB peaking response; finite bounds, settings persistence, live updates, paused-state preservation and graphic-EQ coexistence verified.
- [x] **02. F0133** Configurable bass shelving filter. — Original entries: R0392. Evidence: AudioEffects / native AddBass. Captured 50 Hz/4 kHz stereo fixture verifies low-frequency boost and high-frequency level retention.
- [x] **03. F0048** Low-pass headphone crossfeed with adjustable amount and cutoff. — Original entries: R0150,R0273,R0470. Evidence: AudioEffects / native Effects. Captured left-only PCM verifies filtered opposite-ear content; live native acknowledgement verified. Stereo only; disabled by default.
- [x] **04. F0134** Linked peak-envelope compressor with threshold, ratio, attack, release and makeup gain. — Original entries: R1400,R0982. Evidence: Native Effects / AudioEffectsWindow Dynamics. Actual captured loud-tone PCM proves gain reduction. This replaces the earlier ineffective option-only compression path; automatic loudness normalization remains separate and pending.
- [x] **05. F0135** Linked instantaneous sample-peak limiter with adjustable ceiling. — Original entries: R0275. Evidence: Native Effects. Captured PCM proves the -12 dBFS sample ceiling. No look-ahead or true-peak limiting is claimed.
- [x] **06. F0136** Stereo balance with independent left/right attenuation. — Original entries: R0471,R1503. Evidence: Native Effects. Captured hard-left fixture verifies right-channel attenuation and retained left level.
- [x] **07. F0137** Individual gain for decoded logical channels 1-8. — Original entries: R0021,R0271,R0472. Evidence: Native Effects / Channel controls. Stereo PCM proves -12 dB on one channel without changing the other. Bounds -24 to +12 dB. Complete physical surround mapping is not asserted.
- [x] **08. F0138** Individual delay for decoded logical channels 1-8. — Original entries: R0473. Evidence: Native Effects / Channel controls. Actual impulse response verifies 100 ms left delay while preserving the right-channel impulse. Bounds 0-200 ms; physical speaker assignment remains output-dependent.
- [x] **09. F0139** Mid/side stereo width enhancement, including mono fold-down. — Original entries: R0393. Evidence: Native Effects. Captured left-only PCM verifies changed side amplitude and stereo width. Range 0-2; stereo only.
- [x] **10. F0140** Echo with adjustable delay, feedback and wet amount. — Original entries: R0388. Evidence: Native Effects / Time effects. Actual impulse capture verifies the delayed repeat. Bounded feedback and native time buffers.
- [x] **11. F0141** Short multi-tap reverb with wet amount and decay controls. — Original entries: R0385. Evidence: Native Effects / Time effects. Actual impulse capture verifies the multi-tap tail; this is a compact room effect, not convolution reverb.
- [x] **12. F0142** Flanger with modulated short delay, rate, depth and wet controls. — Original entries: R0386. Evidence: Native Effects / Time effects. Captured PCM differs from bypass and remains finite.
- [x] **13. F0143** Chorus with longer modulated delay, rate, depth and wet controls. — Original entries: R0387. Evidence: Native Effects / Time effects. Captured PCM differs from bypass and remains finite.
- [x] **14. F0144** Stereo center voice reduction through common-center subtraction. — Original entries: R0394. Evidence: Native Effects / Tone and stereo. Captured correlated center tone is canceled. Centered instruments can also be removed; this is not AI stem separation.
